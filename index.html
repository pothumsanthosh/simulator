Space: Run / Pause Circuit Simulation

R: Rotate selected component 90°

H: Flip selected component horizontally

V: Flip selected component vertically

Delete / Backspace: Delete selected component or wire

Ctrl + Z: Undo last change

Ctrl + Y: Redo

Click Pin: Start wiring / complete wire

Click Switch: Toggle SPST switch Open / Closed live

Scroll Wheel: Zoom In / Out

Middle Click / Drag: Pan Schematic
