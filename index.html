How It Works

From schematic or code to numerical analysis in four straightforward steps.

01

Select a Lab

Choose between Circuit Studio, Arduino IDE, Dynamic Blocks, or Scientific DSP runtime based on your engineering discipline.

02

Design & Wire / Write Code

Place electronic components, drag wires between connection terminals, or write native Arduino C++ and DSP matrix scripts.

03

Run Real-Time Simulation

Press Run to activate client-side mathematical solvers that calculate transient waveforms, nodal voltages, and MCU cycle states.

04

Analyze & Save

Measure waveforms with dual-channel cursors, inspect FFT spectrums, and save your work directly to your local and cloud workspace.
